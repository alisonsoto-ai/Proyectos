# Proyectos de Desarrollo de Software

Repositorio con mis proyectos técnicos, desarrollos web/móviles y prácticas de programación como estudiante de 7.º año de **Técnica en Informática Profesional y Personal**.

## Proyectos incluidos

### 1. Life Line — Plataforma de Donación de Sangre y Plaquetas
Plataforma web orientada a facilitar la organización de donaciones de sangre y plaquetas conectando donantes con sedes de FUHESA.
* **Funcionalidades principales:** Registro e inicio de sesión, reserva de turnos en intervalos de 30 minutos (08:00 a 16:00), gestión de estados de turno (*pendiente, realizado, cancelado*), panel administrativo por sede y envío de notificaciones y recordatorios por correo electrónico.
* **Mi rol:** Desarrollo de backend, base de datos y frontend.
* **Distinciones:** Clasificación a instancia provincial en ACTE (2026) y pase a instancia internacional (Paraguay) en las muestras internacionales de San Miguel y Rojas.

### 2. Sistema Integral de Asistencia Escolar *(próximamente / en carga)*
Sistema web y aplicación móvil para la gestión de asistencia de preceptores y control por parte de directivos.
* **Funcionalidades principales:** Alta de alumnos, cursos y horarios (con importación desde Excel), toma de asistencia desde móvil, consulta de historial por DNI, cierre de planillas y flujo de autorización de modificaciones por directivos.
* **Mi rol:** Desarrollo frontend y backend del módulo web de preceptores e implementación de la API para conectar la web con la aplicación móvil.
